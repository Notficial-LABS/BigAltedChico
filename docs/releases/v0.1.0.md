# BigAltedChico v0.1.0 — First Public Preview

BigAltedChico is a monophonic voice transformer by **Notficial LABS**, developed by **Leonardo Marcelo**.

## Downloads

| Platform | Architecture | Included formats |
| --- | --- | --- |
| macOS 12 or newer | Apple Silicon (arm64) | AU, VST3, Standalone |
| Windows 10/11 | x64 | VST3, Standalone |

Use the macOS ZIP to preserve the installer's custom Finder icon, then extract and open the `.pkg`. On Windows, run the `Setup.exe`. Select the formats you want during installation.

Linux and Intel Mac builds are not included in this release. VST2 and AAX are not supported.

Also included: **BigAltedChico-SkinKit-v1.zip**, a ready-to-edit JSON/SVG kit with authoring guides and examples, and **BigAltedChico-0.1.0-corresponding-source.tar.gz**, containing the project plus the exact JUCE source files used for these builds. `SHA256SUMS.txt` covers the attached downloads.

## Features

- Pitch and formant shifting with optional linked controls.
- Transpose, chromatic Quantize and Robot tuning modes.
- Drive and dry/wet Mix controls.
- **LIVE:** approximately 30 ms processing latency.
- **Quality:** approximately 150 ms processing latency, prioritizing audio quality.
- Three skins: **Juguete, Ondas and Salem**.
- UI scaling at 75%, 100% and 125%.
- Preset management and a JSON/SVG template for custom skins.
- BAC icons for the installers and Standalone applications.

## Installation and first use

Close your DAW and BigAltedChico before installing.

On macOS, choose **all users** to install the Standalone in `/Applications`, or **only me** to install in `~/Applications`. Plugin paths follow the same system/user scope. Changing scope does not remove a copy previously installed in the other location.

On Windows, the installer uses the standard all-users locations in Program Files and Common Files/VST3, with a Start Menu shortcut for the selected Standalone component.

Rescan plugins in your DAW after installation. New instances start with **00 Clean Start**, with Mix at minimum: raise Mix to hear the effect. The Standalone starts with Clean on launch; DAW projects restore saved parameters.

## Preview status and known limitations

- Both installers have been manually tried by the developer. Broader hardware/DAW compatibility, upgrade and uninstall validation is ongoing.
- Windows binaries were cross-compiled for x64. Windows audio and host behavior have not received the same automated validation as macOS.
- Windows installers are not Authenticode-signed. macOS packages are not Developer ID-signed or notarized; macOS application bundles use development ad-hoc signatures.
- The latency figures describe processing delay, not complete microphone-to-speaker latency. Audio-interface and DAW buffers add further delay. Neither mode is zero-latency.
- At 48 kHz, offline and VST3 test-host measurements matched the reported latency: 1440 samples in Live and 7200 in Quality. Direct Ableton UI confirmation was obtained for Quality; direct Live confirmation remains pending.
- Live trades spectral detail and low-note accuracy for speed. Quality is preferable when fidelity matters more than response time.
- Updates are installed manually; there is no automatic updater.
